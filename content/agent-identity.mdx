# Agent Identity (ERC-8004)

Pantr is registered as an on-chain AI agent under [ERC-8004](https://eips.ethereum.org/EIPS/eip-8004), a standard for verifiable AI agent identity on EVM chains.

## What Is ERC-8004?

ERC-8004 is an ERC-721-based identity registry that lets AI agents publish a verifiable on-chain profile — who they are, what they do, and how to interact with them. Metadata is stored on IPFS and anchored to the registry contract.

The registry is deployed at the same address on all supported chains:
```
0x8004A169FB4a3325136EB29fA0ceB6D2e539a432
```

## What It Gives Pantr

- **Verifiable identity** — anyone can confirm Pantr is a legitimate registered AI agent owned by a specific wallet
- **Discoverability** — listed on [8004scan.io](https://www.8004scan.io) alongside other agents in the ecosystem
- **Permanent record** — metadata on IPFS cannot be altered; URI updates via `setAgentURI` create an auditable history on-chain
- **Ecosystem readiness** — as agent marketplaces, reputation systems, and agent-to-agent coordination protocols emerge around ERC-8004, Pantr is already registered and can plug in

## Updating the Metadata

If Pantr's details change (new skills, new endpoint, version bump), run:

```bash
node scripts/update-agent-uri.js
```

This re-uploads the metadata to IPFS and calls `setAgentURI` on both Base and Mantle. Requires `MANTLE_AGENT_KEY` and `PINATA_JWT` in `.env`.
