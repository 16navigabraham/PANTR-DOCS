# Admin Dashboard

Private Next.js app — `admin.pantr.xyz`.

---

## Auth

Password lives in `ADMIN_SECRET`. Flow:

1. Any page hit → `proxy.ts` checks `admin_session` cookie
2. No cookie → redirect to `/login`
3. Enter password → POST `/api/auth` → sets httpOnly cookie (24h)

Cookie is `httpOnly + secure + sameSite=strict` — JS can't read it, only the server.

| File | What it does |
|------|-------------|
| `proxy.ts` | Next.js 16 proxy — gates every route |
| `app/api/auth/route.ts` | POST sets cookie, DELETE clears it (logout) |
| `app/api/proxy/[...path]/route.ts` | Server-side proxy — attaches `Authorization: Bearer` before forwarding to pantr-server |
| `app/login/page.tsx` | Login form |

## API Proxy

All admin API calls go through `/api/proxy/[...path]`. It checks the session cookie, attaches `Authorization: Bearer <ADMIN_SECRET>`, then forwards to `https://api.pantr.xyz/api/admin/...`. The secret never touches the browser.

## Pages

### Overview (`/`)
Platform stats with time range switcher (24h / 7d / 30d) — volume, trades, unique traders, revenue estimate. Three charts: volume, trades, new signups.

### Users (`/users`)
Active premium subscribers + last 20 signups.

### User Profile (`/users/[id]`)
Full user — wallets, premium status, trade stats, trade history, settings.

### Traders (`/traders`)
Top 20 by realized P&L.

### Tokens (`/tokens`)
Most-traded tokens — tab by volume or count.

---

## Cmd+K Search

`Cmd+K` anywhere → search by Telegram username or ID → click result → inline quick card (balance, stats, premium). Click through to full profile.

Components: `components/users/user-search.tsx`, `components/users/user-quick-card.tsx`

---

## Deployment

Vercel. Set `ADMIN_SECRET` and `PANTR_API_URL` in Vercel project settings.
Custom domain `admin.pantr.xyz` → CNAME to Vercel in Cloudflare.
