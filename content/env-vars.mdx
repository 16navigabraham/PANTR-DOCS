# Environment Variables

## pantr-server (Render)

| Variable | Description |
|----------|-------------|
| `DATABASE_URL` | Neon Postgres connection string |
| `REDIS_URL` | Upstash Redis — conversation history + rate limits |
| `TELEGRAM_BOT_TOKEN` | From @BotFather |
| `ANTHROPIC_API_KEY` | Claude API |
| `PRIVY_APP_ID` | Privy app ID |
| `PRIVY_APP_SECRET` | Privy app secret |
| `PRIVY_WALLET_API_URL` | Privy server wallet endpoint |
| `JWT_SECRET` | JWT signing secret |
| `ADMIN_SECRET` | Admin dashboard password + `/api/admin` auth |
| `SOLANA_RPC_URL` | Helius or QuickNode |
| `BASE_RPC_URL` | Base RPC (Alchemy or QuickNode) |
| `BASE_FLASHBOTS_RPC_URL` | Flashbots Protect — hides Base trades from MEV bots |
| `JUPITER_API_URL` | Jupiter swap aggregator |
| `FRONTEND_URL` | Main CORS origin |
| `CORS_ORIGINS` | Extra origins comma-separated (analytics.pantr.xyz, admin.pantr.xyz) |
| `TELEGRAM_API_ID` | From [my.telegram.org/apps](https://my.telegram.org/apps) — required for MTProto alpha tracking |
| `TELEGRAM_API_HASH` | From [my.telegram.org/apps](https://my.telegram.org/apps) — required for MTProto alpha tracking |
| `SENDGRID_API_KEY` | Email for account recovery codes |
| `FROM_EMAIL` | Sender address for those emails |
| `PORT` | Default 3000 |

## pantr-admin (Vercel)

| Variable | Description |
|----------|-------------|
| `ADMIN_SECRET` | Must match the one on pantr-server exactly |
| `PANTR_API_URL` | `https://api.pantr.xyz` |

## pantr-analytics

Static HTML, no env vars. API URL is hardcoded in `index.html` — update the `const API` line if it ever changes.

---

`ADMIN_SECRET` is the same value on both server and admin — the admin proxies it as a Bearer token and the server checks it.

Never commit `.env` files. Render injects vars at runtime so no `.env` needed there. Locally, copy `.env.example` → `.env`.
