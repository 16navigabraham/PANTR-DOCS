# Pricing Model

Pantr uses **post-paid pay-per-use** pricing. Users pay only for what they use, with no subscriptions.

## Core Value: Alpha Auto-Buy

Pantr's primary value is the **alpha caller tracking feature** — when a tracked caller posts a contract address, Pantr automatically executes a buy. This is the only feature that incurs charges.

## Pricing Structure

| Feature | Cost |
|---------|------|
| Trade execution (buy/sell) | 2% of trade amount |
| Alpha auto-buy (tracked caller posts CA) | $1 flat per auto-buy |
| Auto-sell (TP/SL) | Free |
| Manual trades | 2% of trade amount |
| All other features | Free |

## User Tiers

### Demo Mode (isDemo = true)
- **Cost:** FREE
- **Charges:** None — all features unlimited
- **Expiry:** Never (no time limit)
- **Use case:** Users testing the bot before committing funds

### Premium (Grandfathered)
- **Cost:** FREE until `premiumUntil` date
- **Charges:** None during premium period
- **After expiry:** Fallback to standard pay-per-use ($1 per alpha auto-buy)
- **Use case:** Users who paid for premium before the model changed

### Standard (Post-Paid)
- **Cost:** $1 per alpha auto-buy + 2% on all trades
- **Charges:** Deducted from wallet after successful execution
- **Required:** Active wallet with balance (SOL, ETH, or MNT)

## How It Works

### Demo User Flow
```
1. User joins → isDemo = true
2. User tracks alpha callers
3. Caller posts → Pantr auto-buys
4. NO CHARGE (demo exempt)
5. User can trade freely until they disable demo
```

### Standard User Flow
```
1. User has isDemo = false AND premiumUntil < now
2. Tracks an alpha caller
3. Caller posts contract address
4. Pantr executes buy + charges $1 from wallet
5. Charge recorded in alpha_charges table
6. If wallet has insufficient balance → charge fails, auto-buy skipped, user notified
```

### Grandfathered Premium User Flow
```
1. User has premiumUntil = 2026-07-15 (still active)
2. Tracks alpha callers
3. Caller posts → Pantr auto-buys
4. NO CHARGE (still within premium period)
5. At 2026-07-16 → isDemo = false, premiumUntil expires
6. Next auto-buy → $1 charge applies
```

## Charging Logic

When `chargeAlphaAutoBuy()` is triggered:

1. Check if user should be charged (exempt if demo/premium)
2. If exempt → no charge, continue
3. If charged:
   - Find user's active wallet
   - Calculate charge amount in native asset
   - Execute blockchain transfer to treasury
   - Sign via Privy custody
   - Record in `AlphaCharge` table
4. Return success/failure status

### Failed Charges

If charge fails:
- Alpha auto-buy is **skipped** (no trade executed)
- Dev is notified via error channel
- No user notification (prevents confusion)
- Charge is recorded as failed for audit

## Database Schema

### User Model (Updated)
```prisma
model User {
  isDemo       Boolean   @default(true)
  premiumUntil DateTime? // grandfathered premium expires at this date
}
```

### AlphaCharge Model (New)
```prisma
model AlphaCharge {
  userId       String
  alphaGroupId String?  // which caller triggered the charge
  chargeType   String   // "alpha_auto_buy"
  amountUsd    Float    @default(1.0)
  chain        String?  // blockchain network
  txHash       String?  // blockchain tx hash
  status       String   @default("charged")
}
```

## Log Messages

| Log | Meaning |
|-----|---------|
| `[ALPHA:CHARGED]` | $1 charge succeeded, txHash recorded |
| `[ALPHA:CHARGE_FAILED]` | $1 charge failed, auto-buy skipped, user notified |
| `shouldChargeForAlpha: user exempt (demo or premium)` | No charge applied — user in demo or premium period |

## Migration from Old Model

### Before (Subscription)
```
$10/month premium subscription
1 free alpha trade/day
Unlimited for premium users
```

### After (Pay-Per-Use)
```
$1 per alpha auto-buy (only feature that's charged)
Demo: unlimited free trades
Standard: pay $1 when you use it
```

### Grandfathering Premium Users

Users who paid for premium before the switch:
- Keep their premium access until `premiumUntil` expires
- No charge during that period
- No refunds
- After expiry: $1 per alpha auto-buy

This ensures fairness and avoids chargeback risk.
