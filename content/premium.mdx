# Pricing Model

Pantr offers **two payment options** — users choose their preferred model.

## Core Value: Alpha Auto-Buy

Pantr's primary value is the **alpha caller tracking feature** — when a tracked caller posts a contract address, Pantr automatically executes a buy. This is the feature that incurs charges under pay-per-use.

## Pricing Structure

| Feature | Pay-Per-Use | Premium ($20/month) |
|---------|------------|-------------------|
| Trade execution (buy/sell) | 2% of trade amount | 2% of trade amount |
| Alpha auto-buy (tracked caller posts CA) | $1 flat per auto-buy | Unlimited (no per-trade charge) |
| Auto-sell (TP/SL) | Free | Free |
| Manual trades | 2% of trade amount | 2% of trade amount |
| All other features | Free | Free |

## User Tiers

### Demo Mode (isDemo = true)
- **Cost:** FREE
- **Charges:** None — all features unlimited
- **Expiry:** Never (no time limit)
- **Use case:** Users testing the bot before committing funds

### Premium Subscription ($20/month)
- **Cost:** $20/month recurring
- **Charges:** None for alpha auto-buys; 2% platform fee on trades (same as pay-per-use)
- **Upgrade/downgrade:** Anytime (no lock-in)
- **Wallet required:** Active wallet with balance to deposit funds and pay 2% trade fees
- **Use case:** Users who auto-buy frequently and want no per-trade charge

### Pay-Per-Use (Standard)
- **Cost:** $1 per alpha auto-buy + 2% on all trades
- **Charges:** Deducted from wallet after successful execution
- **Wallet required:** Active wallet with balance (SOL, ETH, BNB, MNT, or TON)
- **Use case:** Users who use alpha features selectively

## How It Works

### Demo User Flow
```
1. User joins → isDemo = true
2. User tracks alpha callers
3. Caller posts → Pantr auto-buys
4. NO CHARGE (demo exempt)
5. User can trade freely until they disable demo
```

### Premium Subscriber Flow
```
1. User subscribes: $20/month premium plan
2. Tracks alpha callers
3. Caller posts contract address
4. Pantr executes buy
5. NO CHARGE for the auto-buy (premium included)
6. 2% platform fee deducted on the token sale (same as pay-per-use)
7. Can upgrade/downgrade anytime (prorated billing)
```

### Pay-Per-Use User Flow
```
1. User has isDemo = false AND no active premium subscription
2. Tracks an alpha caller
3. Caller posts contract address
4. Pantr executes buy + charges $1 from wallet
5. Charge recorded in alpha_charges table
6. If wallet has insufficient balance → charge fails, auto-buy skipped, user notified
```

## Charging Logic

When `chargeAlphaAutoBuy()` is triggered:

1. Check if user should be charged (exempt if demo/premium)
2. If exempt → no charge, continue
3. If charged:
   - Find user's active wallet
   - Calculate charge amount in native asset
   - Execute blockchain transfer to treasury
   - Sign via Privy custody
   - Record in `AlphaCharge` table
4. Return success/failure status

### Failed Charges

If charge fails:
- Alpha auto-buy is **skipped** (no trade executed)
- Dev is notified via error channel
- No user notification (prevents confusion)
- Charge is recorded as failed for audit

## Database Schema

### User Model (Updated)
```prisma
model User {
  isDemo       Boolean   @default(true)
  premiumUntil DateTime? // grandfathered premium expires at this date
}
```

### AlphaCharge Model (New)
```prisma
model AlphaCharge {
  userId       String
  alphaGroupId String?  // which caller triggered the charge
  chargeType   String   // "alpha_auto_buy"
  amountUsd    Float    @default(1.0)
  chain        String?  // blockchain network
  txHash       String?  // blockchain tx hash
  status       String   @default("charged")
}
```

## Log Messages

| Log | Meaning |
|-----|---------|
| `[ALPHA:CHARGED]` | $1 charge succeeded, txHash recorded |
| `[ALPHA:CHARGE_FAILED]` | $1 charge failed, auto-buy skipped, user notified |
| `shouldChargeForAlpha: user exempt (demo or premium)` | No charge applied — user in demo or premium period |

## Multi-Chain Charging

Premium and pay-per-use models work across **all 5 chains**:

- **Solana** — charges in SOL
- **Base** — charges in ETH
- **BSC** — charges in BNB
- **Mantle** — charges in MNT
- **TON** — charges in TON

Users can auto-buy on any chain. Premium subscription covers all chains (no per-chain cost).

## Supported Payment Methods

All charges are post-paid from active wallets:

| Chain | Native Asset | Charged For |
|-------|-------------|------------|
| Solana | SOL | Alpha auto-buy ($1 equiv), 2% trade fee |
| Base | ETH | Alpha auto-buy ($1 equiv), 2% trade fee |
| BSC | BNB | Alpha auto-buy ($1 equiv), 2% trade fee |
| Mantle | MNT | Alpha auto-buy ($1 equiv), 2% trade fee |
| TON | TON | Alpha auto-buy ($1 equiv), 2% trade fee |

Premium subscribers skip the per-trade charge on all chains.
