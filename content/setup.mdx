# Setup & Deployment

## Prerequisites

- Node.js 20+
- Neon Postgres database
- Upstash Redis instance
- Telegram bot token (from @BotFather)
- Anthropic API key
- Privy account (app ID + secret)
- Solana RPC (Helius recommended)
- Base RPC (Alchemy recommended)

## Local Development

```bash
git clone <repo-url>
cd pantr-server
npm install
cp .env.example .env    # Fill in required vars
npx prisma migrate dev  # Run migrations
npm run dev             # Start with nodemon
```

## Environment Variables

### Required

| Variable | Description |
|----------|-------------|
| `NODE_ENV` | `development` or `production` |
| `PORT` | Server port (default: 3000) |
| `DATABASE_URL` | Neon pooler connection string |
| `DIRECT_DATABASE_URL` | Neon direct connection (migrations) |
| `UPSTASH_REDIS_REST_URL` | Upstash Redis REST endpoint |
| `UPSTASH_REDIS_REST_TOKEN` | Upstash auth token |
| `JWT_SECRET` | JWT signing secret (min 16 chars) |
| `TELEGRAM_BOT_TOKEN` | From @BotFather |
| `ANTHROPIC_API_KEY` | Claude API key |
| `PRIVY_APP_ID` | Privy app ID |
| `PRIVY_APP_SECRET` | Privy app secret |
| `SOLANA_RPC_URL` | Solana mainnet RPC |
| `BASE_RPC_URL` | Base mainnet RPC |

### Optional

| Variable | Default | Description |
|----------|---------|-------------|
| `ERROR_REPORT_BOT_TOKEN` | — | Separate TG bot for error alerts |
| `ERROR_REPORT_CHAT_ID` | — | TG chat for error alerts |
| `SENTRY_DSN` | — | Sentry error tracking |
| `TREASURY_WALLET_SOLANA` | — | Fee collection (SOL) |
| `TREASURY_WALLET_BASE` | — | Fee collection (Base) |
| `CLAUDE_MODEL` | `claude-sonnet-4-20250514` | Model for DMs |
| `CLAUDE_GROUP_MODEL` | `claude-haiku-4-5-20251001` | Model for groups |
| `DEFAULT_SLIPPAGE_BPS` | `500` | Default slippage (5%) |
| `MAX_SLIPPAGE_BPS` | `1500` | Max allowed slippage (15%) |
| `PLATFORM_FEE_BPS` | `200` | Trade fee for all users (2%) |
| `PREMIUM_PRICE_USD` | `10` | Monthly premium price |

## Database

```bash
npx prisma migrate dev    # Dev migrations
npx prisma db push        # Push schema (prod via pooler)
npx prisma generate       # Regenerate client
npx prisma studio         # Visual DB browser
```

**Neon Postgres notes:**
- Use the **pooler** URL for `DATABASE_URL`
- Use the **direct** URL for `DIRECT_DATABASE_URL`
- Prisma auto-appends `pgbouncer=true&connection_limit=10` for pooler URLs
- If auto-suspend is enabled, first query after sleep takes 1-3 seconds

## npm Scripts

| Script | Command |
|--------|---------|
| `npm start` | Start production server |
| `npm run dev` | Start with nodemon (auto-restart) |
| `npm test` | Run all tests |
| `npm run lint` | ESLint check |
| `npm run lint:fix` | ESLint auto-fix |

## Health Checks

| Endpoint | Checks |
|----------|--------|
| `GET /health` | DB + Redis connectivity |
| `GET /health/jobs` | Background job status, activity gate |

## Production Deployment

```bash
npm install
npx prisma generate
npx prisma db push
npm start
```

Set all env vars on the host platform (Railway, Render, VPS, etc.).
