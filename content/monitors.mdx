# Monitors System

Premium-only. Four types: price alerts, limit orders, wallet trackers, DCA. All in the `monitors` table.

---

## Schema

```prisma
model Monitor {
  id          String        @id @default(cuid())
  userId      String
  type        MonitorType
  status      MonitorStatus @default(ACTIVE)
  config      Json
  description String?
  createdAt   DateTime      @default(now())
  lastChecked DateTime?
  triggeredAt DateTime?
}

enum MonitorType   { PRICE_ALERT LIMIT_ORDER WALLET_TRACKER DCA }
enum MonitorStatus { ACTIVE TRIGGERED CANCELLED PAUSED }
```

`config` is a JSON blob holding all the type-specific fields.

---

## Types

**PRICE_ALERT** — notify when price crosses threshold. No trade execution.
Config: `tokenAddress, chain, targetPrice, direction (above|below)`

**LIMIT_ORDER** — execute a buy or sell when price hits target. Fires once, then status → `TRIGGERED`.
Config: `tokenAddress, chain, targetPrice, direction, action (buy|sell), amountUsd, percentage, slippageBps`

**WALLET_TRACKER** — watch an external wallet for buys. Optionally mirror them.
Config: `walletAddress, chain, mirror (bool), mirrorAmountUsd`

**DCA** — buy a fixed USD amount every N hours. Tracks `buyCount` internally, stops at `maxBuys`.
Config: `tokenAddress, chain, amountUsd, intervalHours, maxBuys`

---

## Poller

`src/jobs/monitor-poller.js` — runs every 60s.

Loads all `ACTIVE` monitors → checks each by type → on trigger: execute action + update status + notify user via Telegram. Individual monitor errors are caught — one failure doesn't stop the rest.

## Sniper Filters (related, not a monitor)

Set via `update_settings`:
- `sniperMaxAgeSecs` — skip alpha auto-buy if pair is older than N seconds (default 120)
- `sniperMaxPumpPct` — skip if already pumped > N% in last 5 min (default 50)

These only apply to alpha caller auto-buys, not to monitors.
